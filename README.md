# Hyper code

Steps to raise a PR:

Step 1 : Fork the repo.

Step 2: Clone the repo.

Step 3: Create a new branch. ( git checkout -b new-feature)

Step 4: Edit the Source code.

Step 5: Then push the edit to the new branch.

Step 6: In Git-Hub raise the PR. (By Default Git-Hub gives you the option to Raise the PR).
